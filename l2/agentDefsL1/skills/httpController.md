# httpController

One controller per page. `handlers[].route` is the string the plan already
published and the string the L1 inventory reads. The handler names the
usecase. Input and output symbols stay on the binding, and the projection
lists that symbol's fields. The controller does not import L2, touch a
table, or take a grant from another page.
